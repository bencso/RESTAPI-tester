# RESTAPI-tester 🌐🔧

> REST API tesztelő és oktató projekt - Flask-alapú API lekérdezések megjelenítése

## 🎯 Projekt célja

Ez egy REST API tesztelő és oktató projekt, amely Flask és Python használatával készült. A projekt célja API lekérdezések megjelenítése, tesztelése és az API-k működésének megértése. 

## ✨ Funkciók

- 🌐 **REST API tesztelés** - API endpoint-ok gyors tesztelése
- 📊 **Válasz megjelenítés** - JSON formátumú API válaszok vizualizálása

## 🛠️ Technológiák

- **Python** - Backend nyelv
- **Flask** - Web framework
- **HTML/CSS** - Frontend megjelenítés

## 💭 Fejlesztési folyamat

Ez egy oktató projekt, amelynek célja a REST API-k működésének megismerése és gyakorlása.

## 🎓 Tanulási célok

A projekt során gyakoroltam:
- REST API tervezés és implementálás
- API válaszok megjelenítése és vizualizálása
- Backend és frontend integráció

## 🚀 Futtatás

```bash
# Projekt klónozása
git clone https://github.com/bencso/RESTAPI-tester.git
cd RESTAPI-tester

# Függőségek telepítése
pip install flask

# Flask alkalmazás futtatása
python app.py
```

Az alkalmazás elindul, és a böngésződben megtekintheted az API tesztelő felületet.
